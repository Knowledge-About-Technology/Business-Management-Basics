# Money & Business — GitHub Pages Article Pack

This package contains five original, editable HTML5 articles, one shared responsive CSS3 stylesheet, and a simple index page.

## Files
- `index.html` — category landing page
- `style.css` — shared responsive styling
- `build-a-business-budget.html`
- `cash-flow-forecast.html`
- `track-business-expenses.html`
- `prepare-for-tax-season.html`
- `validate-business-idea.html`

## Publish on GitHub Pages
1. Extract the ZIP.
2. Upload the files to your GitHub Pages repository. If you keep articles in a folder, update stylesheet and internal-link paths accordingly.
3. In each article, replace `YOUR-USERNAME.github.io` in the canonical URL with your actual domain and correct path. Add your own domain if you use one.
4. Confirm all official references are still live and relevant to your target jurisdictions.
5. Replace suggested internal links with real published URLs, or remove links to pages that do not exist yet.
6. Add an author name, reviewed/updated date, editorial policy, and contact/about links as appropriate. Do not invent credentials or dates.
7. Test on mobile and desktop; check title, meta description, canonical URL, navigation, and links before requesting indexing.

## Editorial and SEO notes
- Titles, meta descriptions, primary keywords, related keywords, FAQs, and internal-link suggestions are included in each HTML file for editing convenience.
- The keyword fields are editorial guidance, not search-volume claims.
- Tax, accounting, and business obligations vary by jurisdiction. The articles are general educational information, not individualized professional advice.
- Official sources are provided where useful; review them before publication and add the relevant official authority for the countries your audience targets.
- The internal links are suggested paths. Create matching pages or change the paths before publishing.
